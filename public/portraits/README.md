# Pixel Notes 头像

打开 `overview.png` 可以并排看四版头像，以及每版在 32 × 32 像素下的效果。

| 目录 | 头像 |
| --- | --- |
| `mature-original/` | 成熟态原版 |
| `mature-simple/` | 成熟态简化版 |
| `chibi-original/` | 小形态原版 |
| `chibi-simple/` | 小形态简化版 |

每版都有 `transparent/`（透明底）、`white/`（纯白底）和 `ascii/`（字符画）三个目录。透明版保留脸和头发的白色，人物周围和发绺之间的空隙可以透出底色。

| 文件 | 用途 |
| --- | --- |
| `portrait.png` | 1254 × 1254 原尺寸图。透明目录中的这份 PNG 保存了定稿原图。 |
| `portrait-32.png` 等 | 16、32、64、128、256、512 像素的方形 PNG。文件名中的数字是边长。 |
| `portrait.svg` | 可缩放的矢量图。成熟态原版沿用原始 SVG，另外三版从各自的定稿 PNG 描摹。 |
| `portrait.webp` | 原尺寸无损 WebP。 |
| `portrait.ico` | 包含 16、24、32、48、64、128、256 像素七档图层的图标。 |
| `white/portrait.jpg` | 原尺寸白底 JPEG，适合只接受 JPG 的上传表单。 |
| `ascii/portrait.txt` | 纯文本字符画。用等宽字体查看，并关闭自动换行。 |
| `ascii/portrait.ans` | 带真彩色的终端字符画。在支持 ANSI 颜色的终端中输出文件即可查看。 |
